# Lebanon NH Assessment Data Visualization

A Flask-based web application for visualizing Lebanon, NH property assessment data on an interactive map.

## Features

- **Interactive Map**: Centered on Lebanon, NH with OpenStreetMap base layer
- **Parcel Markers**: Clickable markers showing parcel details including:
  - PID (Parcel ID)
  - Location/Address
  - Property Type (Residential/Commercial)
  - Assessment values for 2024 and 2025
  - Percent change in assessment
- **Color-Coded Markers**: Markers colored by assessment change percentage
- **Heatmap Layer**: Toggle-able heatmap showing assessment change intensity
- **Layer Control**: Switch between different map views and overlays

## Installation

```bash
cd lebdata
pip install -r requirements.txt
```

## Usage

Run the Flask development server:

```bash
python lebdata/app.py
```

Then open your browser to: http://localhost:5000

## Data Source

The application reads parcel data from `../workspace/lebanonnh/parcel_details.csv` which should be generated by the `extract_parcel_details.py` script.

## Geocoding

Addresses are geocoded using the Nominatim service (OpenStreetMap). Results are cached in `geocode_cache.json` to avoid repeated API calls.

Note: Initial loading may be slow as addresses are geocoded. Subsequent loads will be faster due to caching.
